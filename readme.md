# MiniRAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot built using Python, LangChain, Hugging Face, ChromaDB, and Ollama.

## Features

- Document loading using LangChain
- Text chunking
- Text embeddings using Hugging Face
- Vector storage using ChromaDB
- Similarity search
- Answer generation using a local LLM

## Technologies Used

- Python
- LangChain
- Hugging Face
- ChromaDB
- Ollama
- Llama 3.2

## How to Run

1. Install Python and Ollama.
2. Install the required Python packages.
3. Download the model:

   ollama pull llama3.2:3b

4. Run the chatbot:

   python rag_chatbot.py
